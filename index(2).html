LeanCloud 配置教程：
① 打开 leancloud.cn 注册/登录 → 控制台
② 「创建应用」选开发版（免费）
③ 应用 → 设置 → 应用凭证 → 复制 AppID、AppKey 填到上面
④ 存储 → 创建 Class，名字填 Draw → 创建
⑤ 点进 Draw 这个 Class → 权限 → 把「查询 find」和「新增 create」都设为「所有用户」，保存
